# Green Side Up

A tiny browser game about entrepreneurship. Open `index.html` in any browser.

- You have a 20-sided die. One side starts green; the other 19 are red.
- Roll a green side and one red side turns green, so your odds improve.
- Roll red and nothing is lost. You can roll forever.
- Three other players roll alongside you with their own dice and luck.
- The only way to lose is to quit. Comparison is the enemy.
